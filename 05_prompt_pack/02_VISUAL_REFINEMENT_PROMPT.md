# GOOGLE AI STUDIO — VISUAL EXPERIENCE REFINEMENT PROMPT

Refine the existing build into a high-quality editorial data story.

Do not change data or evidence claims. Focus on visual storytelling and interaction.

## Desired feeling
The user should begin with anxiety, move into curiosity, discover contradictory evidence, feel the early-career tension personally, and end with an unresolved but informed question about value capture.

## Create visual rhythm
- Chapter openings can be typographic and minimal.
- Evidence sections should become more structured and analytical.
- Use sticky/scrollytelling sequences only when they clarify a changing concept.
- Alternate dense evidence with breathing room.
- Make the evidence drawer feel like part of the design, not legal fine print.

## Reusable motifs
- Bundle → tasks
- Ladder → experience
- Split → productivity versus compensation
- Stack → skills/expertise
- Flow → who captures value

## Do not
- add AI robots, humanoids or brain graphics
- use random 3D particles
- make everything neon
- animate every element
- obscure chart axes/labels for aesthetics
- hide caveats behind tiny footnotes

## Freedom
You may change layout, font pairing, exact colour palette and transition style as long as accessibility, semantic colour roles, evidence clarity and the chapter logic remain intact.
